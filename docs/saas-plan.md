# OilRun SaaS 기획 최종안 v1.0

> **상태**: 1호 정비소 미팅 직전 최종안. 미팅 후 검증된 항목은 ✅, 무효화는 ❌, 신규는 🆕로 표기.
> **작성일**: 2026-05-09
> **변경이력**: v0.1 (초기 가설) → v1.0 (경쟁 분석·가격 한국 시장 반영, Hero 통합 캘린더 확정)

---

## 0. Executive Summary (1페이지 미팅용)

**제품**: 정비소 통합 운영 SaaS — 모든 채널(전화·카톡·네이버·OilRun·자사앱) 예약을 한 곳에서 받고, 직원·지점·매출·고객 이력까지 관리. 출장 정비는 그 안의 한 모듈.

**아키텍처**: **Core + Add-on Modules**. Core는 모든 정비소가 쓰는 기본 (캘린더·고객·매출·알림톡·출장). 모듈은 segment별 추가 (🎬 Creator / 🏢 Fleet / 🛡️ 보험 / 🏬 Franchise — 우선순위 순). 1호 정비소(13만 구독자 유튜버)는 **Creator 모듈 design partner**.

**왜 지금**: 한국 정비소 SW 시장은 (1) 구식 ERP(인트라밴류 — 가격 비공개·UI 낡음)와 (2) 차주 매칭 플랫폼(카닥·마이클 — SaaS가 아닌 광고 모델)로 갈려 있다. **순수 정비소 운영 SaaS는 카테고리 자체가 비어 있다**.

**누구에게**: 직원 5-15명, 다지점 확장을 검토하는 중급 정비소 사장. 1호 정비소(8명 + 2호점 검토)가 ICP 표본.

**가치 한 줄**: "종이장부 + 카톡 + 여러 앱"을 한 화면으로.

**BM**: 월 구독 (Free / 49,000원 / 89,000원). **시트·매칭 수수료 0**. 알림톡은 실비. 다른 정비소로 수평 확장.

**Hero 데모**: 통합 예약 캘린더가 모든 채널을 빨아들여 자동 배정되는 장면.

**전략적 함의**: 기존 OilRun 마켓플레이스 가설은 **park** — Toast 모델로 SaaS가 정비소를 깔면, 그 위에 마켓플레이스 재가동.

## 1. 문제 정의

### 1.1 사장님이 겪고 있을 것으로 추정되는 페인 (가설 — 미팅에서 1순위 검증)
- **예약 채널 분산**: 전화·카톡·네이버·자사앱·출장 플랫폼이 따로 놀아 종이장부·머릿속·여러 앱 동시 관리
- **직원 8명 일정 충돌·배정 어려움**: 누가 언제 무슨 작업 하는지 추적 X
- **2호점 확장 시 운영 가시성 부족**: 본점에 있을 때 2호점 매출·일정 안 보임
- **단골 retention 부재**: 차량별 정비 이력·다음 정비 시기·재방문 알림 시스템 없음
- **매출·정산 불투명**: 메뉴별·정비사별·지점별 손계산
- **신규 서비스 통합성 부재**: 블랙박스·출장 오일 등 새 채널이 기존 시스템에 안 붙음

### 1.2 현재 어떻게 처리하고 있을까?
종이장부 + 카톡 단톡방 + 엑셀 혼합 가능성 높음. 정비소 SW 사용 중일 가능성도 있음 — 미팅에서 "지금 어떤 SW를 월 얼마에 쓰세요?" 직접 질문이 가장 빠른 검증.

## 2. 시장 분석

### 2.1 한국 시장 지형 — 빈 카테고리

| 카테고리 | 대표 | 정체 | 약점 |
|---|---|---|---|
| 전통 ERP/POS | [인트라밴](https://www.intravan.co.kr/) (오토7·하이웨이), [정비마법사](https://www.kabead.com/), 카메이트 | 차량번호 기반 견적·정비이력, PC 설치형/ASP 혼재 | UI 구식, **가격 비공개·영업 견적**, 외부 채널 통합 약함, 출장 워크플로 부재 |
| 차주 매칭 플랫폼 사장님 앱 | [카닥 파트너스](https://partners.cardoc.co.kr/), [마이클 파트너스](https://partners.mycle.co.kr/) (전국 2,000+ 입점) | 차주 견적 송출 받는 입점형 | **운영 SaaS 아님** — 매칭 광고 모델 ("월 사용료 + 견적 건당 수신료") |
| 출장 차주 앱 | [카수리](https://apps.apple.com/kr/app/id968243793) | 출장 오일·배터리 차주 앱 | 정비소 운영 SW 아님, 우리 출장 모듈과 직접 경쟁 |

→ **순수 정비소 운영 SaaS는 한국에 사실상 없음**. 우리가 칠 카테고리가 비어 있다.

| 제품 | 가격 (USD) | KRW 환산 | 강점 |
|---|---|---|---|
| [Tekmetric](https://www.tekmetric.com/pricing) | $199~$439/월 | 28-62만원 | Smart Jobs, 무제한 유저, **가격 공개** |
| Shopmonkey | $199~/월 | 28만원~ | DVI 올인원, 다지점 사례 다수 |
| [AutoLeap](https://autoleap.com/multi-location/) | $199~/월 | 28만원~ | **다지점 전면 셀링** |
| Mitchell 1 | 비공개 | n/a | 30년 업력, OEM 정비 매뉴얼(ProDemand) |
| RepairShopr | $89~/월 | 12만원~ | 범용 수리샵, 자동차 전용 아님 |

소·중형 정비소 SaaS 글로벌 표준 = **월 $179-$199 (~25-28만원)**. 한국 정비소 심리 마지노선 추정 5-12만원/월과 큰 갭 — 가격 가설은 한국 현실 맞춤.

### 2.3 우리 차별화 베팅 (4 pillars)

| 베팅 | 평가 | 근거 |
|---|---|---|
| **출장 정비 네이티브 지원** | ✅ 진짜 빈자리 | 매칭 플랫폼·전통 ERP 모두 미지원. 차주 위치 + 이동시간 + 도착 알림 + 동선 최적화를 정비소 입장에서 푸는 SaaS는 한국 미발견 |
| **다지점 통합** | ⚠️ 한국엔 차별, 글로벌엔 따라잡기 | "8명 + 2호점" ICP에 맞춰 셀링하면 강력 |
| **카카오 알림톡 단골 자동 알림** | ✅ (정보성/광고성 분리 필요) | 카닥·마이클 파트너스는 자사 푸시 위주 — 카톡 네이티브 워크플로 약함 |
| **통합 예약 인박스** | ✅ 정비 도메인 특화는 미발견 | "전화로 충분"이라는 사장님 반응 위험 |

### 2.4 비명백한 인사이트 (미팅 narrative에 직접 반영)
1. **카닥은 매칭으로 시작해 자사 테크샵 차림** → "플랫폼은 결국 직거래 가져간다" 사장님 의심 자동 발생. **순수 구독, 매칭 수수료 0** 명시를 미팅 서두에 깔 것.
2. **정찰제 = 마진 깎임 트라우마** (마이클 모델로 학습됨). 우리 정찰가는 **출장 메뉴 한정**임을 분명히.
3. **무제한 유저가 글로벌 표준** — 시즌성 알바·견습공 회전이 잦아 시트 과금이 분쟁 발화점.
4. **가격 공개 자체가 차별화** — 인트라밴류 영업 견적 vs 우리 홈페이지 가격표 (Tekmetric 따라하기).
5. **DVI는 한국에서 약화될 수 있음** — 카카오톡으로 사진 보내는 게 일상이라 "그게 뭐가 새롭냐" 반응 가능. **승인 흐름까지 묶어야 의미** ("고객이 클릭하면 견적 승인").

- → **GTM wedge**: 유튜버 정비소들은 디지털 친화 + 서로 영향력 있어 first wave로 적합. 일반 정비소로 확산.

## 5. 기능 우선순위 (Core / Module 분리)

### 5.1 Core SaaS — 모든 정비소가 쓰는 기본

#### Core P0 — 미팅 데모 + MVP 구독 시작
- [ ] **통합 예약 캘린더** (모든 채널 인박스, Hero 화면)
- [ ] 직원·자원 배정 — **무제한 유저, 시트 과금 없음**
- [ ] 차량번호 단일 레코드 (차주·차량·정비이력 하나로)
- [ ] 견적서 → 작업지시서(RO) → 결제·세금계산서 흐름
- [ ] 매출 대시보드 (일/월, 메뉴별)
- [ ] 출장 메뉴 (OilRun 채널 + 자체 출장 동선 관리)
- [ ] 카카오 알림톡 (정보성: 예약확인·도착·완료·정기점검 안내)
- [ ] 차주 부킹 페이지 (정비소별 퍼블릭 URL, 메뉴 (a) + 사진 견적 (b))

#### Core P0.5 — 미팅 검증 후 결정
- [ ] **디지털 차량점검(DVI)** — 사진·체크리스트·고객 클릭 승인
- [ ] **2지점 통합 대시보드** — 2호점 확장 고민 직격

#### Core P1 — 구독 정착 후
- 친구톡 (광고성, 별도 요금)
- 직원 인센티브 정산
- 재고 관리 (오일·블랙박스·소모품)
- 차량별 자동 알림 룰 엔진
- 증상 intake (c) 이상 소리/진동, (d) 긴급

#### Core P2 — 확장
- 직원 근태·급여, 마케팅 자동화, 리뷰 관리
- 차주용 앱 (예약 확인·이력)
- **OilRun 마켓플레이스 재가동**

## 6. 화면 & 데모 시나리오

### 6.1 Hero (확정)
**통합 예약 캘린더** = 첫 화면. 모든 채널이 한 인박스로 들어와 자동 배정되는 장면이 1초 wow.

### 6.2 데모 흐름 — Core 7장 + Creator 모듈 2장

**Core 데모 (모든 정비소에 보여줄 것)**:
1. **로그인 후 홈 = 통합 캘린더** (오늘 본점/2호점 일정 한 눈)
2. **새 예약 동시 들어옴** (카톡·전화·OilRun) → 자동 배정 데모
3. **차량/고객 카드** (단골 김OO, 마지막 오일 6개월 전 → 알림톡 발송 버튼)
4. **출장 작업 화면** (정비사 모바일 뷰: 출발/도착/완료)
5. **매출 대시보드** (오늘·이번달 메뉴별)
6. **2지점 비교 뷰** (본점 vs 2호점)
7. **차주 부킹 페이지** (퍼블릭 URL, 메뉴 + 사진 견적)

**🎬 Creator 모듈 데모 (1호 정비소 전용)**:
8. **영상→매출 funnel 대시보드** (영상별 클릭·예약·매출)
9. **부킹 페이지 Creator 버전** (채널 임베드, "어떤 영상 보고 왔어요?" 옵션)

### 6.3 고려했으나 hero에서 제외한 후보
- 2지점 통합 대시보드 → 보조 화면(6번)으로 유지
- 차량별 정비 이력 + 자동 알림 → 화면 3에 흡수
- 정비사 8명 배정·근태 → 화면 7 옵션

## 7. OilRun 플랫폼과의 관계

- 기존 prototype `/order/*` (마켓플레이스 차주 흐름) → **그대로 유지, 미팅에선 보조**
- 기존 prototype `/shop/*` (정비소가 OilRun 주문 받는 화면) → **SaaS 안의 "출장 오일 모듈"로 흡수**
- 새로 만들 **`/saas/*`** = SaaS 본체 (캘린더·다지점·고객·매출 등)

미팅 narrative:
> "기존엔 OilRun 차주 앱과 연결되는 정비소 화면만 있었는데, 사장님 이야기 듣고 보니 진짜 원하시는 건 정비소 자체를 통째로 디지털화하는 거더라구요. 그래서 그 솔루션을 따로 만들고 있고, 출장 오일은 그 안의 한 메뉴입니다."

마켓플레이스 가설은 **park** — Toast 모델로 SaaS가 정비소를 깔면 재가동.

## 8. 비즈니스 모델

### 8.1 모델
- 월 구독 SaaS (B2B)
- **수수료 0**: 매칭·거래 수수료 받지 않음. 카닥의 "매칭→자사 테크샵" 전례 때문에 사장님 의심 선제 차단

### 8.2 가격표 (한국 시장 현실 반영)

**Core**:
| 플랜 | 월 가격 | 포함 |
|---|---|---|
| Free | 0원 | 월 30예약, 알림톡 20건, 1지점, 무제한 유저 |
| **Standard** | **49,000원** | 무제한 예약, 알림톡 100건, 1지점, 무제한 유저, 매출 리포트 |
| **Multi** | **89,000원** | 다지점(2개), 알림톡 300건, 통합 대시보드 |
| 지점 추가 | +29,000원/월 | 3호점부터 |
| 알림톡 초과 | 건당 12원 | 카카오 실비 |
| 출장 메뉴 | 기본 포함 | OilRun 채널 + 자체 출장 |

**Add-on Modules**:
| 모듈 | 월 가격 | 대상 |
|---|---|---|
| 🎬 Creator | **+29,000원** (design partner는 무료/할인) | 유튜브·인스타 운영 정비소 |
| 🏢 Fleet | 미정 (P2) | 법인·렌터카 계약 정비소 |
| 🛡️ 보험 연계 | 미정 (P2) | 사고 수리 비중 큰 정비소 |
| 🏬 Franchise | 미정 (P2) | 본사-가맹 구조 |

### 8.3 가격 원칙
- **시트 과금 금지** (글로벌 SaaS 만장일치 — 정비소는 시즌성 회전 잦음)
- **가격 공개** (Tekmetric식 — 인트라밴 영업 견적과 차별)
- **Free가 trial 역할** (월 30예약·20알림톡으로 핵심 가치 체험)
- **카닥 파트너스의 "월 사용료 + 건당 수신료"** 모델이 사장님에게 익숙 → 우리의 "월 구독 + 알림톡 실비"가 anchor로 작동

### 8.4 검증 액션 (미팅)
"49k / 89k / 199k 중 어디까지 쓰시겠어요?" 가격 던지고 반응 보기. "지금 OO만큼 쓰는데 이게 OO 절감하면 그 가격 가능하냐"로 ROI 환산.

## 부록 A. 이 기획안의 가장 중요한 5가지

미팅 자리에서 한 가지만 기억해야 한다면:

1. **카테고리가 비어 있다** — 한국에 "정비소 운영 SaaS"는 없다. 인트라밴은 구식 ERP, 카닥/마이클은 광고 모델.
2. **Core + Module 아키텍처** — Core SaaS는 모든 정비소 공통, Creator/Fleet/보험 등 모듈은 segment별 추가. 1호 정비소는 Creator 모듈 design partner.
3. **통합 캘린더가 Hero**다. 모든 채널이 한 인박스로 들어오는 장면이 1초 wow.
4. **수수료 0, 시트 과금 0** — 카닥 트라우마와 시즌성 인력 회전을 모두 제거.
5. **Core 49k/89k + 모듈 +29k** — 글로벌 28만원의 1/5 가격, 공개 가격표로 차별화.
6. **출장은 메뉴, OilRun은 park** — Toast 모델로 SaaS가 정비소를 깔면 마켓플레이스 재가동.

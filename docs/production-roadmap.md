# 프로토타입 → 실서비스 전환 로드맵

> 작성일: 2026-05-06
> 대상: OilRun 프로토타입을 1호 정비소(성수자동차정비)와 함께 실서비스로 출시

## 0. 현재 상태 진단

- **있는 것**: UI 흐름, 화면 구조, mock 데이터 모델, 디자인 시스템
- **없는 것**: 백엔드, DB, 인증, 결제, 지도, 알림, 위치 추적, 정산, 법적 장치
- 프로토타입은 "요구사항 명세서"로 활용하고 백엔드부터 새로 쌓는 게 현실적

## 2. 우선순위 로드맵

### Phase 0 — 결정해야 할 것 (코드 짜기 전) ⚠️

#### 사업 모델 확정
- 수수료율 (차주 가격의 X% 또는 정비소당 정액)
- 정산 주기 (주간/월간)
- 환불 정책 (정비사 도착 후 취소는?)
- 배차 거리 제한 (반경 N km까지만 매칭)

#### 법적 검토 (변호사 1회 상담 필수)
- 통신판매업 신고 + 전자상거래법
- 개인정보처리방침 (위치, 차량번호, 결제정보 등 민감정보)
- 정비소-플랫폼 계약서 (정산·책임·해지 조항)
- 작업 중 사고 시 책임소재 → **영업배상책임보험** 필요

#### 자동매칭 규칙 명확화
- "AI 매칭 없음, 정비소가 직접 동선 결정"이 CLAUDE.md 규칙
- 그럼 자동매칭은 무엇 기준? (거리? 선착순? 정비소 평점?)
- 이게 핵심 비즈니스 로직 → 1호 사장님과 합의 먼저

### Phase 1 — MVP (1호 정비소 단독 운영, 6~10주)

유저 1명 + 정비소 1곳으로 제한. 자동매칭 없이 모든 주문 그 정비소로.

- 차주 회원가입/로그인 (휴대폰 본인인증)
- 8단계 주문 흐름 + 실결제 (토스페이먼츠 1개만)
- 정비소 앱: 주문 알림 → 수락 → 상태변경
- SMS 알림 (배정/도착/완료)
- 어드민: 주문 목록·매출 조회만

### Phase 2 — 다중 정비소 (3~5개월)

- 자동매칭 알고리즘
- 정비소 가입·심사 흐름
- 정산 시스템 (세금계산서 포함)
- 정비소 앱 위치 추적 (출발~완료)
- 차주 앱 실시간 위치 표시

### Phase 3 — 확장 (6개월+)

- 카카오/네이버 소셜 로그인
- 리뷰·평점
- 쿠폰·포인트
- B2B (법인 차량 일괄 관리)
- 정비 이력 관리

## 3. 도메인별 필수 작업

### 3.1 인증·계정

| 항목 | 우선순위 | 비고 |
|---|---|---|
| 휴대폰 본인인증 | ★★★ | NICE/KCB, 차주·정비사 모두 |
| 사업자등록번호 검증 | ★★★ | 국세청 API, 정비소 가입 시 |
| 정비사 자격 검증 | ★★ | 자동차정비기능사 자격증 사진+수동 검수 |
| 소셜 로그인 | ★ | Phase 2+ |
| 어드민 2FA | ★★★ | 매출·개인정보 접근 |
| RBAC | ★★★ | 차주/정비소장/정비사/CS/슈퍼어드민 |

### 3.2 데이터 모델

→ 별도 문서: [db-schema-v1.md](./db-schema-v1.md)

### 3.3 주문 상태머신 (가장 위험한 부분)

```
pending → matched → assigned → en_route → arrived
       ↓                    ↓        ↓
  canceled (전액환불)   canceled(?)  working → completed
```

- 정비사가 도착 후 차주 잠적/거절하면? → **출장비 부분환불 정책 필요**
- 결제 → 매칭 실패 → 자동환불 → 알림 (트랜잭션 보장 필수)

### 3.4 결제·정산

- **PG**: 토스페이먼츠 또는 포트원(아임포트) — 카드/카카오페이/네이버페이/계좌이체 한번에
- **에스크로 여부 결정**: 작업 완료 전까지 정비소 미정산 (분쟁 보호)
- **정산**:
  - 주간 정산 + 세금계산서 자동 발행
  - 수수료 차감 후 송금
  - 정비소별 정산 명세서
- **환불 케이스**: 부분환불, 매칭실패 자동환불, 분쟁 환불

### 3.5 지도·위치

- **카카오맵 SDK**: 클라이언트 키 + 서버 키 둘 다 필요
- **지오코딩**: 주소 → 좌표 (카카오 로컬 API)
- **실시간 위치**: 정비사 폰 GPS → 5~10초마다 서버 → WebSocket으로 차주에게 push
- **개인정보 이슈**: 정비사 위치 추적은 본인 동의 + 작업 시간 한정 필수
- 현재 `components/shop/ShopMap.tsx`는 placeholder → 카카오맵으로 교체

### 3.6 알림 시스템

| 채널 | 용도 | 비용·제약 |
|---|---|---|
| 카카오 알림톡 | 배정/도착/완료 (광고 아님, 정보성) | 비즈메시지 사전 등록·승인 필요, 건당 8~15원 |
| SMS (LMS) | 알림톡 실패 시 fallback | 건당 22원 |
| 푸시 (FCM) | 정비소 앱 새 주문 알림 | 무료, 단 앱 필요 |
| 이메일 | 영수증·정산서 | SES/Mailgun |

→ 정비소가 새 주문을 빠르게 인지해야 하므로 FCM 푸시 + 알림음 필수. 웹만으론 부족 → 정비소는 native app(or PWA+푸시) 권장.

### 3.7 외부 API

- **차량번호 → 차종 조회**: 국토부 자동차365 또는 사설 API (KB차차차 등)
- **사업자등록번호 진위**: 국세청 OPEN API (무료)
- **본인인증**: NICE/KCB (월정액 + 건당)
- **세금계산서**: 팝빌, 바로빌 등

### 3.8 보안·컴플라이언스

- HTTPS 전구간 (CloudFront/Cloudflare)
- 개인정보 암호화 (휴대폰·주소·차량번호 → AES-256 at-rest)
- 결제정보는 저장 금지 (PG 토큰만)
- 접근 로그·변경 이력 (audit trail) 1년 이상 보관
- ISMS-P는 매출 100억 이상부터 의무 (초기는 X)

### 3.9 운영·관측

- **Sentry** (에러 추적) — 무료 티어 가능
- **로그 수집**: CloudWatch / Datadog / 또는 직접 (Loki)
- **APM**: Datadog or NewRelic (Phase 2+)
- **DB 백업**: PITR + 일별 스냅샷
- **온콜 체계**: 결제·매칭 장애는 즉시 대응 (1호 사장님 단독일 땐 본인이 온콜)

### 3.10 모바일 앱 전략 (가장 큰 결정)

- **차주**: 웹 (PWA) 충분 — 1회성 사용자 많음
- **정비소**: native 앱 권장 (백그라운드 위치, 푸시 알림, 알림음)
  - React Native or Flutter
  - 빠른 출시 원하면 Expo + React Native (현재 React 코드 일부 재사용)

## 4. 추천 스택

| 레이어 | 추천 | 이유 |
|---|---|---|
| Frontend (웹) | 현재 Next.js 16 유지 | 이미 작성됨 |
| Backend | Next.js Route Handlers (MVP) → NestJS (Phase 2) | 단일팀이면 모놀리식이 빠름 |
| DB | PostgreSQL (Supabase or RDS) | 트랜잭션·관계형 필수 |
| ORM | Prisma | mock-data.ts → 스키마 변환 쉬움 |
| Cache/Queue | Redis (Upstash) + BullMQ | 매칭·알림 큐 |
| Realtime | Supabase Realtime / Pusher / 자체 WS | 정비사 위치·상태 |
| 파일 | S3 (or Supabase Storage) | 차량 사진, 자격증 |
| Hosting | Vercel(웹) + Railway/Fly(백엔드) + Supabase(DB) | 초기 운영 부담↓ |
| 정비소 앱 | Expo (React Native) | 코드 재사용 |
| Auth | NextAuth(Auth.js) + 휴대폰 본인인증 | 검증된 라이브러리 |

## 5. 1호 사장님 미팅 후 즉시 결정해야 할 것

미팅에서 시연만 하지 말고 **이 답을 받아오세요**:

1. 자동매칭 기준 (거리/시간/정비사 컨디션?)
2. 출장 가능 반경 (km) · 시간대 (24시간? 영업시간?)
3. 동시 주문 처리 수 (1대 정비차로 몇 개?)
4. 수수료율 합의안
5. 매칭 실패 시 정책 (대기? 환불? 인근 정비소?)
6. 작업 중 추가 정비 발견 시 (예: 브레이크 패드도 갈아야 함) 결제·승인 흐름
7. 영수증·세금계산서 (개인 차주에게도 발행?)
